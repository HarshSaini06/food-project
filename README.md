# Foodie Hub

Foodie Hub is a simple frontend website created using **HTML, CSS, and JavaScript**. The project is designed to provide a clean and responsive user interface for a food or restaurant website.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Responsive design
- Attractive homepage
- Navigation bar
- Food menu section
- Contact section

## How to Run

1. Download or clone the project.
2. Open the `index.html` file in your browser.
